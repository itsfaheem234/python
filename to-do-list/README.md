# to-do list

a simple command-line to-do list application built with Python. it allows you to add, view, complete, and delete tasks while automatically saving them to a JSON file.

## features

* view all tasks
* add new tasks
* mark tasks as completed
* delete tasks
* automatically save tasks
* load saved tasks when the program starts
* handles invalid input without crashing

## requirements

* Python 3.x

no external libraries are required.

## 🚀 how to run

1. clone or download the repository.
2. open a terminal in the project folder.
3. run:

```bash
python todo.py
```

4. use the menu to manage your tasks.

## 📂 project structure

```text
todo-list/
│
├── todo.py
└── tasks.json
```

`tasks.json` is created automatically when you add your first task.
