# contact-book 

a simple command-line contact book built with Python. it allows you to add, view, search, edit, and delete contacts while automatically saving them to a JSON file.

## features

* add new contacts
* view all contacts
* search for contacts by name
* edit existing contacts
* delete contacts
* save contacts automatically
* load saved contacts when the program starts
* simple command-line interface

## requirements

* Python 3.x

no external libraries are required.

## how to run

1. clone or download the repository.
2. open a terminal in the project folder.
3. run:

```bash
python contact_book.py
```

4. use the menu to manage your contacts.

## project structure

```text
contact-book/
│
├── contact_book.py
└── contacts.json
```

`contacts.json` is created automatically when you add your first contact.
