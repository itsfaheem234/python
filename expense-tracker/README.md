# expense-tracker 

a simple command-line expense tracker built with Python. it allows you to record expenses, view spending, calculate total expenses, organize spending by category, and delete expenses.

## features

* add new expenses
* view all recorded expenses
* calculate total spending
* view spending by category
* delete expenses
* automatically save expenses
* load saved expenses when the program starts
* handles invalid numerical input

## requirements

* Python 3.x

no external libraries are required.

## how to run

1. clone or download the repository.
2. open a terminal in the project folder.
3. run:

```bash
python expense_tracker.py
```

4. use the menu to manage your expenses.

## project structure

```text
expense-tracker/
│
├── expense_tracker.py
└── expenses.json
```

`expenses.json` is created automatically when you add your first expense.
