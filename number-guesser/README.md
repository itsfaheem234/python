# number-guessing-game
a simple beginner-friendly python game where the player tries to guess a randomly generated number between 1 and 100.

## how it works
1) python randomly selects a number between 1 and 100.
2) the player enters a guess.
3) the game tells the player whether the guess is too high or too low.
4) the number of attempts is tracked.
5) the game ends when the correct number is guessed.

## features
1) random number generation
2) unlimited guesses
3) attempt counter
4) higher/lower hints
5) simple command-line interface

## requirements
python 3

## how to run
1) download or clone the repository.
2) open a terminal in the project folder.
3) run ```python numberguesser.py```
4) enter your guesses and try to beat your previous score!
